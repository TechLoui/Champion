## Como isso vira ranqueamento (resumo de execução)

1. **Página de produto** cobre 🔵 marca + 🟢 categoria + parte de 🟠. Já é automática
   (title/description/H1/JSON-LD). Reforçar escrevendo, no cadastro, descrição 300+
   palavras usando os termos 🟠 do produto + 3-4 FAQs reais.
2. **Blog** cobre 🟠 problema (o maior volume) e linka para o produto. É o motor do
   orgânico — cada artigo da lista acima ataca um cluster.
3. **Home/sobre** firmam 🔵 marca e os head terms 🟢.
4. **Mesma lista alimenta os anúncios** (Google Ads/Shopping): os termos 🟢 e 🔵 são os
   de melhor ROI para campanha paga enquanto o orgânico amadurece.

Regra de ouro: **1 intenção dominante por página.** Não tente ranquear "vermífugo" e
"núcleo proteinado" na mesma URL — cada cluster tem sua página/artigo.
